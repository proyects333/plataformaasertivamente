ASERTIVAMENTE — WEB CON PÁGINAS INDEPENDIENTES

ACTUALIZAR EN TU XAMPP
1. Haz una copia de tu proyecto actual.
2. Copia los seis archivos HTML y la carpeta assets dentro de tu proyecto.
   Combina las carpetas y acepta reemplazar los archivos de diseño.
3. CONSERVA TU CARPETA api ACTUAL, especialmente api/db.php.
   No elimines el proyecto entero. No importes SQL. No cambies las tablas.
4. Enciende Apache y MySQL, abre tu dirección habitual y pulsa Ctrl+F5.
Ejemplo: http://localhost/asertiva_mente_aula_virtual/
Usa el nombre real de tu carpeta si es distinto.

PÁGINAS
index.html: Inicio.
nosotros.html: Presentación y enfoque.
programas.html: Catálogo real y búsqueda.
programa.html: Detalle de un programa mediante ?id=ID_REAL.
metodologia.html: Funcionamiento y preguntas frecuentes.
aula.html: Acceso, registro y plataforma de estudiantes/profesores/admin.

ESTRUCTURA
public.css y public.js: páginas públicas.
aula.css y app.js: acceso y plataforma.
Las API PHP incluidas son idénticas al ZIP original. Conserva las que ya tienes
si personalizaste la conexión en XAMPP. No se modifica la base de datos.
El catálogo consume api/cursos.php?action=publicos.
No hay cursos de ejemplo ni precios o acreditaciones inventados.
Para cargar los cursos e iniciar sesión usa Apache, no file://.

VALIDACIÓN

registro y certificados deben verificarse allí con tus cuentas existentes.

CORRECCIÓN DE ACCESO
Reemplaza todos los HTML y assets. Conserva api y tu base de datos.

muestran en pantalla y los recursos tienen versión para evitar caché anterior.

PANEL DE GESTIÓN ACADÉMICA — admin.html
Después de iniciar sesión con tu cuenta de administrador o profesor, pulsa
Administrar en tu aula. También puedes abrir:
http://localhost/asertivamente_aula/plataformaasertivamente/admin.html

Incluye: Inicio con totales reales, creación y consulta de cursos, creación,
edición y eliminación de clases, enlaces YouTube/PDF, creación y consulta de
usuarios y asignación de profesores (solo administrador).
Los profesores ven en este panel solo los cursos cuyo profesor_id corresponde
a su cuenta. El servidor conserva las comprobaciones de permisos existentes.
Los alumnos no pueden usar el panel de gestión.
No se agregan ventas, pasarela de pagos, eventos ni productos descargables
independientes. Los materiales PDF siguen vinculados a las clases.
Los cursos creados aparecen en el catálogo según el comportamiento original.
No se crean cuentas admin nuevas ni se cambian contraseñas.

ARCHIVOS NUEVOS
admin.html, assets/css/admin.css y assets/js/admin.js.
El botón Administrar de aula.html abre el nuevo panel.
Copia los HTML y assets combinándolos con tu carpeta actual. Conserva api.
No se ejecutan migraciones ni se modifica la base de datos para instalar.
Las acciones que realices desde el panel sí guardarán cambios en tu base
mediante las API existentes, igual que el formulario de administración anterior.
